# 🚀 Trilha html modulo 1
## Primeiro desafio solicitado na formação básica de html

Elaborar um website, utilizando uma estrutura bem básica, utilizando tags aprendidas durante as aulas práticas:
 
### Utilizar todas as tags explicadas nas aulas: 
- <h1> até <h6>; 
- <p>; 
- <mark>; 
- <small>; 
- <i>; 
- <u>; 
- <strong>; 
- <ol>; 
- <ul>; 
- <li>; 
- <a>; 
- <hr>; 
- <sub>; 
- <sup>; 
- <blockquote>;

### Utilizar novas tags sugeridas: 
- <font>; 
- <del>; 
- <p>; 
- <abbr>; 

Obs: A ideia é buscar estas tags na internet, entender como ela funciona e utilizar no texto.
